Almari

Your epub library, standing on a wooden bookcase where your wallpaper used to be.

Almari draws a real bookcase on the Wayland background layer, stands every book in your folder on its shelves, and opens any one of them into a full reading view when you click it. Nothing to alt-tab to. Your desktop is a bookshelf whenever nothing is covering it.

Install it Source on GitHub
Use this with end-4's illogical-impulse.

That is the setup Almari is built for and the only one it is tested on. Under illogical-impulse the shell starts and stops it with your session, gives it global shortcuts and its own page in the settings app, steps its wallpaper and panel aside so the shelf is clickable, and hands it your current wallpaper and colour palette.

Almari will run under plain Hyprland — it is an ordinary layer-shell client — but you will be wiring up autostart, keybinds and theming yourself, and nothing outside illogical-impulse is tested. If you do not have the shell yet, install it first.

What it is

A bookcase, not a book list

  • It reads your library. Point it at a folder and every .epub under it becomes a book. Cover art, title and author come out of the file; the spine takes its colour from the cover and its thickness from the file size, so the shelf looks like your shelf.
  • It is drawn like furniture. Planks, uprights, a top beam, a shadow under every shelf. The last book on a part-filled shelf leans onto its neighbour — and only ever onto something that can actually hold it up, never into open air.
  • Books open where they are. Click one and the wallpaper becomes a reader: chapters, contents, search, your remembered position, a progress bar. A page turn lands on exactly the line the last screen ran out on, never half of one.
  • It stays out of the way. It lives below every window, so it is only there when your desktop is. Nothing is on screen that is not a book — no toolbar, no gear icon.

Install · four steps

Getting it on your desktop

Arch and derivatives are the tested path. On anything else, install the four dependencies with your own package manager first and the rest is the same.

  1. Have illogical-impulse running

    Almari plugs into it rather than replacing any part of it. If your bar, settings app and wallpaper already come from end-4's dots, you are ready. If not, follow the shell's own setup guide before going further.

  2. Clone and run the installer

    $ git clone https://github.com/qahrindustries/Almari
$ cd Almari
$ ./install.sh

    This puts almari in ~/.local/bin, writes a starter config, and installs the icon and desktop entry. It only asks for your password if gtk4, gtk4-layer-shell, python-gobject or python-cairo are actually missing — so re-running it later to update is quiet and safe.

  3. Add the shell integration

    Three files live under quickshell/ in the clone. The first is dropped in whole; the other two are snippets to merge into files you already have.

    $ cp quickshell/services/Almari.qml ~/.config/quickshell/ii/services/

    Then paste quickshell/modules/common/Config.options.qml into the background block of your modules/common/Config.qml, and quickshell/modules/settings/BackgroundConfig.section.qml into modules/settings/BackgroundConfig.qml. Add Almari.load() next to the other services in shell.qml. Optionally copy packaging/keybinds.example.lua into ~/.config/hypr/custom/keybinds.lua for the shortcuts below.

  4. Point it at your books and switch it on

    Open the shell's settings app, go to Background → Almari bookshelf, and turn Enable on. The shelf appears immediately and will come back with every login. Set your library folder in Almari's own settings card — double-click the shelf — or from the terminal:

    $ almari ctl set books_dir ~/Books
$ almari ctl rescan

    If nothing appears, hyprpaper or swww is probably still running and competing for the same layer. Stop it.

Using it

Everything happens on the shelf

There is no toolbar and no gear icon, on either the shelf or the reader. Five gestures cover the whole program.

Do thisGet this
Click a bookOpen it, at the page you left
Double-click anywhereSettings — on the shelf or inside a book
Drag a bookRearrange the shelves; the order is saved
Right-click a bookIts details and progress, and whether it stands as a cover, a spine or leaning
Esc, or a click outsideClose whichever card is open

A single click waits out the double-click interval before it opens anything, so a double-click meant for the settings never opens a book on its way past.

Settings

One place, and it stays put

Double-clicking opens the settings card, and everything it changes is written straight to ~/.config/almari/config.json. That file is the only owner of these values — the shell deliberately keeps no copy, which is what stops a login from overwriting what you chose.

Per-book views

Right-clicking one book lets it ignore the shelf-wide setting: Auto, Cover, Spine or Tilted. A book only ever leans onto something that can hold it up — the book beside it, or the case wall. One with nothing to rest against stands upright, because leaning into open air is what a book does on its way to lying flat, not a pose it holds.

Control socket

Driving it from anywhere

almari ctl talks to the running shelf over a Unix socket. It answers before GTK is even imported, so it is cheap enough to put on a key.

$ almari ctl toggle-reader          # open/close the last book read
$ almari ctl open "Animal Farm"     # by title or path fragment
$ almari ctl random
$ almari ctl settings               # open the settings card
$ almari ctl wallpaper toggle       # wallpaper behind the shelves
$ almari ctl book-state tilt "Animal Farm"
$ almari ctl set scale 1.4
$ almari ctl get                    # the whole config, as JSON
$ almari ctl state                  # what it is doing right now
$ almari ctl rescan
$ almari ctl quit

While a book is open, page-down, page-up, next-chapter, prev-chapter, toc and find work too. Your library folder, the config file and the shell palette are all watched, so adding a book or editing a setting takes effect without a restart.

If something is wrong

The usual four

The shelf is not there at all.
Another wallpaper daemon is holding the layer. Stop hyprpaper or swww and toggle Almari off and on again. Check it is actually running with almari ctl state.
The shelf is there but clicks go through it.
Clicks reach the background layer only when nothing is above it. The shell's own background panel steps aside for Almari automatically — if it has not, Almari.qml is probably not in ~/.config/quickshell/ii/services/, or Background.qml was never pointed at it.
It is empty.
almari ctl get will show you which folder it is looking in. Only .epub files are picked up, and it looks in subfolders too. After moving books about, almari ctl rescan.
A setting will not stick.
It should — that is what ~/.config/almari/config.json being the single owner is for. If it does not, check that an older copy of the shell integration is not still pushing its own values; the current Almari.qml sends only the wallpaper path and whether the wallpaper shows behind the shelves.

For the curious

What it is made of

One Python file, GTK4 through PyGObject, wlr-layer-shell for the surface, and cairo for every plank and spine. The quickshell side is one QML singleton and two snippets. The test suite writes itself a real epub, so a fresh clone can check its own paging, gestures and layout without needing your library:

$ ./tests/run.sh
